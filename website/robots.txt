# ── AI crawlers are allowed, deliberately ────────────────────────────────
# The blanket "User-agent: *  Allow: /" below already permits them; the named
# blocks are here so the policy is a visible decision rather than an accident
# of the default, and so there is one obvious place to change it.
#
# The reasoning: this is a consultancy that sells AI automation. Being
# quotable in an AI answer is the product working, not a leak. Cloudflare's
# managed file took the opposite position and disallowed every one of these.
#
# To opt out of any of them, change its Allow to Disallow.

User-agent: *
Allow: /

# The demo is noindex and its API is not content. Keeping crawlers out of
# /api/demo/ also keeps them from burning the rate limits meant for visitors.
Disallow: /api/demo/
Disallow: /demo/
